# engine-deepinfra

Engine wrapper for **deepinfra** — the uniform interface that the Image and
Video Generators call instead of talking to the provider directly.

Generated by `new_engine.py` from the provider's own OpenAPI document. Every
entry below came from that document; nothing was invented.

| Endpoint | Media | Prompt | Summary |
|---|---|---|---|
| `deepinfra/llm` | LLM | none | Deploy Create Llm |
| `deepinfra/speech` | AUD | none | Openai Audio Speech |
| `deepinfra/transcriptions` | AUD | none | Openai Audio Transcriptions |
| `deepinfra/translations` | AUD | none | Openai Audio Translations |
| `deepinfra/completions` | LLM | none | Openai Chat Completions |
| `deepinfra/completions` | LLM | required | Openai Completions |

| `deepinfra/variations` | IMG | none | Openai Images Variations |

| `deepinfra/text-to-speech` | AUD | none | Text To Speech |

| `deepinfra/videos` | VID | required | Create Video Generation |
| `deepinfra/add` | AUD | none | Create Voice |
| `deepinfra/edit` | AUD | none | Update Voice |

## The interface

```python
from engine_deepinfra import Engine, InputFile

engine = Engine(profile, output_dir, api_key=None, on_progress=None)
results = engine.run([InputFile(path=..., prompt=...)])
```

`Engine.__init__` is pure. `run()` returns one result per input file, or one
per saved asset, and never raises for a per-file failure — `EngineError` is
reserved for pre-flight (missing endpoint, bad concurrency, missing key).

## Setup

```
export DEEPINFRA_API_KEY=...
pip install -r requirements.txt
```

Base URL: `https://api.deepinfra.com/v1/openai`

## Tests

```
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest -q
```

Two suites run: this engine's own tests, and the shared conformance suite
(`engine-conformance`) that every engine in the fleet must pass. Passing it is
the gate.

## Scope

Image and video only (`engine-mgmt/SCOPE.md`). Chat, embedding and speech
models are observed and skipped, never carried.
